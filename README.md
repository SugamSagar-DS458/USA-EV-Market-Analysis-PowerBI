# 🚗 Electric Vehicles (EV) Market Analytics Dashboard

## 🎯 Project Overview
This repository contains an end-to-end Power BI data analysis project focused on the rapidly evolving Electric Vehicle (EV) market. The dashboard transforms complex, raw data into an interactive visual narrative, designed to help stakeholders quickly grasp market trends, adoption rates, and technological shifts.

## 💡 Business Value & Key Insights
*   **Market Penetration:** Identified key geographic regions leading in EV adoption and the infrastructure driving this growth.
*   **Growth Trends:** Visualized year-over-year sales volume, highlighting seasonal peaks and long-term consumer shifts.
*   **Segment Analysis:** Broke down market share by vehicle type (e.g., Battery Electric vs. Plug-in Hybrid), revealing consumer preferences and manufacturer dominance.

## 🛠️ Technical Stack & Skills Applied
*   **Tool:** Microsoft Power BI
*   **Data Processing:** Power Query (ETL processes, handling missing values, and standardizing formats)
*   **Data Modeling:** Optimized relational models for fast query performance
*   **Calculations:** Advanced DAX (Data Analysis Expressions) for dynamic measures, year-to-date (YTD) growth, and custom KPIs
*   **Visualization:** Interactive charts, dynamic slicers, and a clean, user-centric UX/UI design
